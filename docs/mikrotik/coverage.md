98 MCP operation tools plus profile/catalog discovery tools. Tool schemas retain read-only properties for listing and omit them from mutation parameters.

Operations are an explicit allowlist, not a claim that every menu supports every REST method. Creation requirements and field omissions are reviewed overrides in `tools/mikrotik/catalog-spec.json`; each operation records applied override notes and its source URL. Firmware/package differences can make an operation unavailable. Firmware discovery is not a complete feature probe.

No unrestricted command execution, scripts, account management, lifecycle commands, backup/restore, packet capture, or continuous monitoring is exposed. Writes execute immediately, with no transaction or rollback and no automatic retries. Static-only tools refuse existing dynamic entries after a fresh read; concurrent changes by other administrators are still possible.
